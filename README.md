# CampusHub
A platform specifically made for students that brings study groups, campus events, and useful resources together in one place. With CampusHub, students can :
-Find and create Study groups.
-Find, add and join Campus events.
-Find useful learning resources and add new ones.
## Technologies Used
-HTML
-CSS
-JavaScript
-LocalStorage
## How it works
CampusHub is a simple web application where students can explore different sections of campus life, such as:
1. Study Groups: search for existing groups or create new ones.
2. Events: search for events, create new ones, and join events.
3. Resources: search for learning materials or add new ones.
4. LocalStorage: keeps created groups, events, participants, and resources all saved in the browser.
